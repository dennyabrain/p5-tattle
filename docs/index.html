▸ perspectiveGrid1(config)

Generates a one-point perspective grid that fills the entire canvas.

Reference points are sampled along a single continuous arc of the canvas boundary (the "lower U": left edge from vpY downward → bottom edge → right edge back up to vpY). For each reference point P on the arc, the chord is extended through the vanishing point to the exit point Q on the opposite boundary. Because P moves continuously along the arc, adjacent chords always share nearby endpoints — eliminating the angle-flip that caused cross-lines to jump.

With drawLines:

  • within-column connections → the converging radial lines
  • same-step across columns → concentric cross-lines that converge at VP

Config is forward-compatible with multi-point perspective. Future generators (perspectiveGrid2, perspectiveGrid3, …) accept the same fields with additional entries in vanishingPoints.

perspectiveGrid1(config: object)
Parameters
config (object)
Name Description
config.width number Canvas width in pixels.
config.height number Canvas height in pixels.
config.cellSize number Spacing between radial lines along the reference arc, and approximate spacing between cross-lines.
config.vanishingPoints Array<[number, number]> Array of [x, y] vanishing point coordinates. perspectiveGrid1 reads only vanishingPoints[0]. Keep this consistent across all perspective variants.
Example
perspectiveGrid1({
  width: 600, height: 600, cellSize: 60,
  vanishingPoints: [[300, 300]]
})

▸ gridWithPerlin(sketch, options = {})

Displaces each grid point by a Perlin noise value sampled at its own coordinates. Both axes are shifted by the same noise sample, producing a diagonal warp. Larger level values create more visible distortion.

▸ offset(config)

Shifts each grid point along one axis by an amount that accumulates with each column (or row). Column 0 is unshifted, column 1 shifts by amount, column 2 by 2 * amount, and so on — creating a shear effect.

offset(config: object): function (grid): EnhancedIterable
Parameters
config (object)
Name Description
config.axis string (default 'column') Which index drives the shift. 'column': shift vertically, increasing per column. 'row': shift horizontally, increasing per row.
config.amount number Pixels to shift per step.
Returns
function (grid): EnhancedIterable:
Example
// Shear columns downward — each column 5px lower than the last
pipe(squareGrid(config), offset({ amount: 5 }))
// Shear rows rightward
pipe(squareGrid(config), offset({ axis: 'row', amount: 8 }))

▸ sine(config)

Displaces grid points along one axis using a sine wave driven by the other axis.

sine(config: object)
Parameters
config (object = {})
Name Description
config.amplitude number (default 20) Peak displacement in pixels.
config.frequency number (default 1) Cycles across the full grid width/height.
config.phase number (default 0) Phase offset in radians.
config.axis string (default 'y') Axis to displace: 'x' or 'y'.
config.inputAxis string (default 'x') Axis used as the sine input: 'x' or 'y'.
Example
// Ripple rows vertically — one full wave across the grid width
pipe(squareGrid(config), sine({ amplitude: 30, frequency: 1 }))
// Animate the wave by advancing the phase each frame
pipe(squareGrid(config), sine({ amplitude: 20, frequency: 2, phase: sketch.frameCount * 0.05 }))
// Stack two waves — vertical ripple on rows, horizontal ripple on columns
pipe(
  squareGrid(config),
  sine({ amplitude: 20, frequency: 2 }),
  sine({ amplitude: 20, frequency: 2, axis: 'x', inputAxis: 'y' })
)

▸ drawInRegion(sketch, region, fn)

Calls fn with a map(u, v) function that converts proportional coordinates (u and v each in 0–1) to actual pixel coordinates inside the region using bilinear interpolation across its corners.

Corner winding (matching cells.js): corners[0] = top-left, corners[1] = top-right, corners[2] = bottom-right, corners[3] = bottom-left

drawInRegion(sketch: p5, region: Region, fn: Function)
Parameters
sketch (p5) The p5 instance.
region (Region) A region object from a walker (has .corners ).
fn (Function) Callback receiving map(u, v) => [x, y] .
Example
drawInRegion(sketch, region, (map) => {
  sketch.beginShape()
  sketch.vertex(...map(0, 0))
  sketch.vertex(...map(1, 0))
  sketch.vertex(...map(1, 1))
  sketch.vertex(...map(0, 1))
  sketch.endShape(sketch.CLOSE)
})

▸ radialWalker(grid, config)

Walks a grid radially, emitting regions in order of their distance from a given origin point — closest regions first. Works for any grid shape since distance is measured from each region's centroid.

radialWalker(grid: object, config: object): Iterable<RadialRegion>
Parameters
grid (object) A grid object as returned by a generator or pipe.
config (object = {}) Configuration.
Name Description
config.origin [number, number] [x, y] point to measure distance from.
Returns
Iterable<RadialRegion>:
Example
// Colour cells by distance from canvas centre
for (const region of radialWalker(gridObj, { origin: [300, 300] })) {
  const t = sketch.map(region.distanceToOrigin, 0, 420, 0, colors.length - 1)
  sketch.fill(colors[Math.floor(t)])
  drawRect(sketch, region)
}
// Animate an expanding ring effect
const maxDist = sketch.frameCount * 2
for (const region of radialWalker(gridObj, { origin: [300, 300] })) {
  if (region.distanceToOrigin < maxDist) drawDiamond(sketch, region)
}
